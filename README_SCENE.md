# HACHBOB Scene exp6 — FarZ без поиска GameMode

**Заменён неработавший путь ZFar.** Кнопка больше не ищет `dota_gamemode`: новый модуль выбирает параметр непосредственно по инструкциям функции камеры из присланного отчёта. Рабочие Zoom exp4 и код отключения дымки сохранены.

## Запуск

1. В старом Scene нажми **«Вернуть оба»** и закрой его. Рабочий Zoom можно оставить открытым.
2. Распакуй новый архив отдельно и запусти **`SCENE.bat`**. В заголовке должно быть **exp6**.
3. В пробе героя нажми **ZFar**. Для обычной ветки камеры задаётся 18000, либо сохраняется уже имевшееся большее значение.
4. Дымку при необходимости включи той же отдельной кнопкой.

Повторное нажатие выключает режим; «Вернуть оба», обычное закрытие и End пытаются вернуть исходные значения. Старт всегда OFF. Никаких новых JSON или ручных адресов для запуска не нужно. Если будет отказ — достаточно текста либо `zoom/scene.log`.

**Изменён способ управления FarZ, но устранение чёрной области в твоей живой сцене ещё не подтверждено.** ON означает подтверждённую установку параметра, а не измеренную дальность рендера. Если чёрная область является границей геометрии карты или отдельным отсечением ландшафта, один FarZ её не устранит.

## Что исправлено

- Убрана зависимость кнопки ZFar от обнаружения GameMode. Не используются подбор чисел, поиск cvar по приблизительному имени, старое `camera +0x2A4`, VEngineCvar из форума или патчи функций.
- По RIP-relative инструкциям **проверенного метода FarZ** вычисляются ссылки на селектор/флаг камеры, обычный слот данных и альтернативная таблица. Выполняется та же проверка ветки, которая видна в присланном коде. Данные не выбираются по одному правдоподобному float.
- Для обычного статического слота требуется законченная и неизменившаяся инициализация. Неинициализированный слот не принуждается к работе. В другой ветке запись допускается только в реально доступные RW-данные; защита страниц не меняется.
- Меняются ровно 4 байта выбранного параметра, **не машинный код и не указатель vtable**. Значения старого неподходящего GameMode-пути не трогаются.
- При смене источника, чужом изменении или неизвестной сборке режим останавливается, без постоянного перезаписывания.
- Возвращаются точные исходные байты — в том числе −1, если был автоматический режим. Слот принадлежит модулю, поэтому при смене камеры возврат возможен без обращения к старому объекту, но только при прежних PE/коде/инициализации и ожидаемых наших байтах.

Проверки не атомарны относительно игры. Частичная запись, чужие изменения, завершение процесса или изменение кода могут сделать возврат невозможным. Принудительное завершение Python не восстанавливает память. При неподтверждённом возврате и оставшемся эффекте перезапусти Dota.

## Сохранённые возможности и ограничения

- Ползунок дистанции — прежний Zoom exp4, отдельный `ZOOM.bat`. Второй экземпляр уже работающего Zoom не нужен.
- Дымка — прежние `C_FogController.m_fog.maxdensity`, `C_EnvCubemapFog.m_flFogMaxOpacity`, `C_EnvVolumetricFogController.m_flScattering`; исходный модуль поиска/записи/возврата сохранён побайтно.
- Туман войны, скрытые противники, погода, частицы и DLL на диске не меняются. Нет инжекта, удалённых вызовов и снятия защитных флагов cvar.
- Известный профиль — PE timestamp `1790705915`, размер `115027968`, проверенные RTTI и хеши методов. Не обещается совместимость с обновлениями, любым режимом камеры или отсутствие античит-риска.
- Большее FarZ может увеличить нагрузку и ухудшить точность глубины.

## Проверки

- **30 новых синтетических тестов**, в том числе работа без GameMode, выбор ветки, инициализация, отмена, чужая/частичная запись, смена камеры/сцены, возврат, End/закрытие.
- Zoom/Scene: **167 тестов прошли**. Полный проект: **1119 тестов, 1116 пройдены, 3 пропущены** (Mono отсутствует).
- Реальное Tk-окно и worker проверены на искусственной памяти: GameMode отсутствует, FarZ включается/возвращается, дымка работает независимо, активный зум 1500 не меняется.
- Все 18 файлов принятого Zoom exp4, модуль дымки и 12 файлов Last Hit/KS/ввода сохранены без изменений.
- **Windows API и живая Dota здесь не запускались.** Новую реализацию ещё нужно проверить на визуальном результате у тебя.

Нужен прежний 64-битный Python 3.11 с tkinter, без новых pip-пакетов. Происхождение: `FARZ_EXP6_ANALYSIS.md`, `zoom/NOTICE.md`, `SCENE_SOURCE.md` (история exp5). Новые файлы распространяются под MPL-2.0. Хеши текущего пакета — `zoom/SCENE_MANIFEST.json`; `zoom/MANIFEST.json` относится к неизменённому Zoom exp4.
