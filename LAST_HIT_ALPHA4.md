# Last Hit alpha4 — обнаружение → помощник → решение → ввод

## Запуск

Полный комплект. Закрой старый HACHBOB, распакуй в новую папку, запусти `start.bat`.

Настройки Dota **не меняются относительно alpha3**: Quick Attack **выкл.**, автоатака **«Никогда»**, атака **A**, Stop **S**, выделен свой герой. Если бинды другие, укажи их в дополнительных настройках Last Hit.

Insert → Скрипты → Last Hit → включить. После закрытия меню **подсветка прочитанных крипов появляется без удержания Mouse4**. Для автоматических атак по умолчанию удерживай Mouse4. Можно выбрать «Нажатие · вкл / выкл»; состояние переключателя не сохраняется между запусками. Включение самого модуля после запуска всегда OFF.

- **«Только помощник»** оставляет чтение/подсветку, но запрещает атаки и Stop.
- **«Пауза при ручных командах» по умолчанию ВЫКЛ.** При включении новые ручные команды дают короткую паузу автоатаке. Отмена отложенного Stop при ручном вмешательстве работает независимо от этой опции: Stop не должен оборвать твою новую команду.
- Удерживаемая физическая кнопка, которую нужно синтезировать, не дублируется. Фокус, меню, служебные клавиши, занятость героя и свежесть по-прежнему проверяются. Выключение ручной паузы не убирает эти ограничения.

## Что реально переделано

### 1. Обнаружение линейных крипов

Обрабатываются **мечник, дальний/«маг», знаменосец и катапульта**, обе команды, обычные и upgraded/mega-имена. Катапульта вида `npc_dota_badguys_siege` больше не теряется из-за отсутствия слова `creep` в имени.

Фоновое обнаружение читает полную ограниченную таблицу entity (до 32768 индексов), а не только `highestEntityIndex`: этот показатель может занижаться, и основной reader ранее отдельно восстанавливал героев, но не крипов. Скана всей памяти процесса нет; ввод из этого worker не отправляется.

Поддержаны RTTI Lane/Siege и базовый Creep **только при подтверждённом линейном имени**, в том числе прочитанном из `m_iszUnitName`. Нейтралы, призывы и герои не объявляются линейными по близости или похожему HP.

**Для цели больше не обязательны параметры её собственной атаки** — attack point, скорость её снаряда, её интервал и поворот. Для решения читаются HP/maxHP, команда, состояние жизни, доступность, позиция, броня, реген и hull. Тайминг полной атаки нужен герою; для прогноза башни её собственные атакующие поля остаются обязательными.

### 2. Подсветка не зависит от того, разрешена ли сейчас автоатака

До 24 прочитанных крипов в допустимой области экрана получают маленькую метку с типом и **HP / нижним расчётом урона**:
- зелёная — расчётное окно ластхита;
- голубая — расчётное окно деная;
- жёлтая — ожидание HP/атаки либо подготовка;
- серая — вне дальности;
- красная, урон `?` — данных для расчёта урона недостаточно.

Крупная плашка остаётся у выбранной/отправленной цели. Исчезнувшие и устаревшие цели не сохраняются как последние известные позиции. Метки — **не гарантия попадания или убийства**: занятость героя, конкурирующие удары и проверки отправки могут запретить действие даже при подходящем HP.

В меню и на экране отдельно показываются количества по четырём типам, число в дальности, число готовых целей и ошибки чтения/классификации. В логе раз в две секунды при включённом модуле — `LASTHIT PIPELINE`: обнаружено → прочитано → дальность → готовность, причины отбраковки и источник AS. Фраза «нет окна» больше не скрывает все эти этапы.

### 3. Урон и скорость атаки

Урон героя и броня цели по-прежнему читаются из живых полей. Принудительный запас 8% из alpha3 **сброшен в 0%** при переходе на alpha4; остаётся базовый запас 3 HP. Дополнительный процент можно настроить вручную. Чужие таблицы баланса не загружаются.

Добавлено чтение живых `bonus_attack_speed` через owner/type/stability-проверенный modifier vector для **Power Treads, Phase Boots, Wraith Band**, а также нескольких поддержанных предметов: Gloves, Hyperstone, Moon Shard, Assault. Две Wraith Band не схлопываются в одну. Ловкость берётся из `m_flAgilityTotal`, поэтому при переключении Treads используются текущие атрибуты, а не постоянное число из веб-таблицы. Если у Phase Boots в этой установке значение AS равно нулю, добавляется ноль, а не выдуманный бонус.

При изменении BAT, базовой AS, ловкости или прочитанной прибавки старая калибровка интервала сбрасывается. Похожие длинные паузы между отдельными ластхитами больше не могут произвольно замедлить эту оценку.

**Это частичное чтение AS, не универсальный GetAttackSpeed.** Условные/процентные модификаторы, замедления и другие эффекты охвачены не полностью. При неудачном чтении используется явно помеченная оценка базы + ловкости. Новые modifier-поля и их смысл ещё не проверены в живом запуске этой версии. Схема не содержит типов этих полей, поэтому поддержаны только однозначные ограниченные int/float-представления; неоднозначность отклоняется.

Для катапульты дополнительно читается `CDOTA_Modifier_Creep_Siege.incoming_hero_damage_penalty`. Значение трактуется как процент снижения входящего урона героя; это **пока не подтверждённая в твоём runtime интерпретация**. Нельзя прочитать/проверить — катапульта остаётся видимой, но не выбирается автоматически с выдуманным множителем. Отсутствие модификатора считается нулевой поправкой только после проверки полного стабильного вектора. Прогноз урона башни по катапульте по-прежнему приблизительный.

### 4. Автоматизация сохранена, но отделена от помощника

Отправка идёт через прежний общий sender: Dodger → KS → Last Hit. По умолчанию враг получает прицельный ПКМ, союзник — A+ЛКМ. Старый Quick Attack остаётся опцией. Нет второй независимой мыши, внутреннего AttackTarget, самостоятельного маршрута, погони за целью вне дальности или управления несколькими юнитами.

Режим одной атаки/отложенного Stop из alpha3 остаётся доступным. Его ограничение прежнее: момент завершения замаха оценивается, а не подтверждается engine-событием запуска снаряда. Ручная команда, приоритет KS/Dodger, потеря контекста и остановка активации отзывают отложенный Stop. В режиме переключателя остановка активации — второе нажатие, а не отпускание кнопки.

## Что доказано этим выпуском — и что нет

В присланном журнале alpha3 нет `LASTHIT sent`, есть многочисленные ручные паузы. **По нему нельзя доказать, сколько крипов reader находил и почему остальные не стали целями:** старый лог этой информации не содержал. Исправлены обнаруженные недостатки кода, но нельзя утверждать, что один из них был единственной причиной именно того запуска.

Добавлены 30 регрессий, включая настоящую функцию сканирования entity на синтетической таблице с заниженным highest index, цепочку capture → planner для всех четырёх типов, чтение modifier vector, режимы удержания/переключения и подсветку без ввода. Полная проверка и сборка — `test-results.txt`.

**Windows/Dota alpha4 здесь не запускалась.** Offline-тесты не подтверждают точность кликов, всех модификаторов, FoW, выбранного юнита или добивания. Это не эквивалент Umbrella и не обещание «крип точно умрёт». Камера не возвращалась; KS/Dodger не расширялись. Новые записи боёв для применения архива не нужны.
