# Справка разработчика: каталог профилей способностей

Этот документ описывает источник игровых чисел и состав каталога. Он не является инструкцией по пользовательскому редактированию: приложение не позволяет создавать или менять профили, новые записи выпускает разработчик.

## Источник значений и совместимость

В качестве ближайшего публичного набора взят **OpenDota/Dotaconstants**, snapshot commit [`bf193a550f778dec35debf4d71d05a86bebcc418`](https://github.com/odota/dotaconstants/commit/bf193a550f778dec35debf4d71d05a86bebcc418), опубликованный 19.09.2026. Он следует за публичным патчем Dota 2 **7.41f** (официальная [страница патча](https://www.dota2.com/patches/7.41f)). У offsets пользователя `dwBuildNumber=6356260` и клиентский timestamp 26.09.2026; эта близость дат делает 7.41f разумным кандидатом, **но не доказывает**, что значения клиента пользователя совпадают с публичным набором.

Offsets — это адреса/смещения структур памяти, а не таблицы урона, дальности или задержки. Поэтому активные обычные профили приведены к публичному набору 7.41f, а новые шаблоны добавлены в `ks_profiles.json` выключенными. Перед включением сверяйте локальный клиент и клавиши quickcast. После запуска AUTO остаётся OFF; этот предохранитель не заменяет проверку.

## Добавленные шаблоны

Ниже перечислены предварительно заполненные шаблоны разработчика по публичному snapshot. Они **выключены по умолчанию** и не отображаются в пользовательском списке поддерживаемых героев, пока разработчик не включит и не проверит соответствующий профиль:

|---|---|---:|---|
| Beastmaster | Primal Roar | R | Только основной прямой компонент, не боковой урон |
| Dragon Knight | Dragon Tail | W | Базовая дальность 150; расширение формы/предметов не учитывается |
| Leshrac | Lightning Storm | E | Первое попадание, отскоки не суммируются |
| Broodmother | Spawn Spiderlings | R | Первое попадание |
| Night Stalker | Void | Q | Прямое попадание |
| Bounty Hunter | Shuriken Toss | Q | Базовое первое попадание; бонусы отскоков/талантов не суммируются |
| Spirit Breaker | Nether Strike | R | Только базовый магический компонент; атака/bash не прибавляются |
| Sniper | Assassinate | R | Только бонусный магический компонент; физический урон атаки не прибавляется |
| Chen | Penitence | Q | Начальный pure-компонент |
| Witch Doctor | Paralyzing Cask | Q | Базовый первый hit; повторные отскоки не суммируются |
| Wraith King | Wraithfire Blast | Q | Только начальный hit, без DoT |
| Venomancer | Snakebite | W | Только начальный hit, без тиков/атака-триггеров |
| Spectre | Spectral Dagger | Q | Point-попадание по наблюдаемой неподвижной цели; урон по другим целям не суммируется |
| Sand King | Burrowstrike | Q | Prefill для point-линии; **выключен**, поскольку каст перемещает героя и может завести его в опасную позицию |

Четыре прежние сложные заглушки остаются вне плоской модели: Sun Strike (Exort/распределение/динамический слот), Reaper's Scythe (процент недостающего HP), Culling Blade (порог казни) и Powershot (заряд/канал/ослабление по пути). Sand King теперь имеет заполненный flat-черновик, но остаётся выключенным из-за перемещения героя. Zeus Cloud не добавлен как рабочий профиль: периодический урон не поддержан. Puck Illusory Orb оставлен выключенным: публичное описание помечает его vector-targeted, а текущий ввод проекта умеет только обычный point quickcast, не drag/release.

## Ограничения

- `flat` — прямой урон по таблице уровня плюс необязательный коэффициент INT. Вспомогательные тики, полные отскоки, Scepter/Shard, таланты, spell amp, барьеры и все особые условия не считаются, если заметка профиля не говорит иначе.
- Для лучевого/point/no-target AoE шаблона может требоваться наблюдаемая неподвижность цели. Это не предикт будущей позиции; при неизвестном движении такой профиль пропускается.
- Диапазоны и время — исходные значения/консервативные параметры из выбранного набора, не динамически извлечённая дальность из памяти. Формы героя, временные баффы и пользовательские бинды могут их менять.
- В Queen of Pain Scream of Pain заполнен `self_damage_fraction=0.25`: перед отправкой оценивается самоурон, и каст пропускается, если эта оценка может убить героя. Это консервативный ограничитель, не полная модель здоровья/перехилов.
- «SENT» означает, что клавиша была отправлена, а не что способность попала или убила.

Пользовательское меню предназначено только для выбора героя из списка поддерживаемых и сессионных переключателей. Профили, их значения и список поддерживаемых способностей изменяет разработчик в релизном каталоге после проверки модели.
