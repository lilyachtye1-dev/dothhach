# Разовая проверка Last Hit после обновления

Это диагностическое дополнение к установленному HACHBOB LastHit alpha4, **не готовая alpha5** и не повторный импорт offsets. Рабочий KS, настройки, Dodger и сборка меню не меняются. Камера не добавляется.

## Что сделать

1. Распакуй файлы из архива **в свою текущую папку HACHBOB**, рядом со `start.bat`. Используй ту папку, где ты уже применил новые offsets. Старый полный архив поверх неё не распаковывай.
2. Закрой HACHBOB и его консоль/feed. Саму Dota оставь запущенной.
3. Зайди в демо с любым живым управляемым героем. Ничего покупать, атаковать или записывать не нужно. Крипы рядом необязательны.
4. Запусти `CHECK_LAST_HIT_PATCH.bat` один раз.
5. Пришли **`last_hit_patch_report.json`** из этой папки. Даже если в отчёте указана ошибка чтения героя или модификаторов, пришли его: сведения о `client.dll` могли уже сохраниться.

Используются существующие Python 3.11 x64 и pymem, как при обычном запуске HACHBOB. Если JSON не появился, пришли текст ошибки из окна. BAT не устанавливает зависимости и не завершает процессы автоматически.

## Зачем это нужно

В присланном дампе содержимое всех 7204 классов совпадает с прежним: смещения полей не изменились. Пять изменившихся глобальных адресов уже применены твоим импортом. Но в JSON нет PE timestamp и SizeOfImage загруженного `client.dll`; `build_number: 48` их не заменяет.

Проверка читает заголовок DLL, до трёх коротких снимков локального героя и до 12 доступных целей рядом. Старое приватное расположение списка модификаторов проверяется только как **неподтверждённая гипотеза внутри диагностики**. Оно не устанавливается в профиль и не передаётся автоматизации. Результат `structural_check: passed` означает лишь прохождение структурных проверок этого чтения — не подтверждение всей механики и не разрешение ввода.

Программа не нажимает клавиши, не кликает, не пишет в память игры и не меняет offsets, профили или защитные проверки. Создаётся только отчёт рядом со скриптом (с временным файлом для атомарного сохранения). Старый отчёт заменяется новым при успешном сохранении. Максимальный размер — 256 КиБ.

Отчёт содержит технические данные: идентификатор процесса, адреса объектов, сведения о DLL, хеш схемы, имена игровых юнитов, прочитанные поля и ошибки. Запись экрана и длительный сбор не выполняются.

## Статус

Это недостающая проверка для продолжения адаптации Last Hit, не заявление о его работоспособности на новой сборке. Защита старой production-версии не снята, её прежние build/layout pins не заменены. Проверки на синтетических данных не заменяют чтение твоего нового `client.dll`.

Для разработчика: `py -3.11 -m unittest discover -s tests -p test_last_hit_patch_probe.py -v`.

Офлайн-проверка дополнения: 24 новых теста пройдены. Полный набор: 777 тестов, 775 пройдены, 2 пропущены из-за отсутствия Mono в среде проверки. Нативные файлы не менялись. Все 528 файлов поставки alpha4 сверены с ранее выданным архивом: изменений и потерь нет. Проверка в новой запущенной Dota здесь не выполнялась.
