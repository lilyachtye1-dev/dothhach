# HACHBOB · KS input FIX · без камеры

## Установка

Закрой прежний HACHBOB через End. Распакуй полный архив в **новую папку**, запусти `start.bat`. Insert → Killsteal → кнопка включения. Камера, её страница, worker и зависимости удалены из этого комплекта. Нативное меню и build_overlay.bat возвращены побайтно к alpha8 FIX1 (с отдельными Killsteal/Dodger). Новых зависимостей нет.

## Исправлено по присланному логу

1. **Enter/Tab больше не сбрасывают Killsteal в OFF.** Отправка временно запрещена, пока клавиша физически удерживается, но сразу после отпускания снова разрешена без повторного нажатия кнопки включения. Нет остаточной задержки 0.25 с.
2. **Убрана общая пауза KS из-за ЛКМ/ПКМ, Alt/Shift/Ctrl и других игровых клавиш.** Изменены обе ступени: принятие решения в ks_service и реальная отправка в ks_input. Не просто удалена надпись в статусе.
3. Для настоящего `ks_core.Decision` используется тот же короткий приоритетный input-путь, что уже применялся для защит alpha6/7. Модификаторы временно отпускаются перед quickcast и восстанавливаются по свежему физическому состоянию, а не по старой копии. Если пользователь сам отпустил Alt во время отправки, Alt не нажимается обратно. При неизвестном/устаревшем состоянии удерживаемых модификаторов попытка пропускается.
4. **Dodger OFF больше не печатает heartbeat каждые 3 с**, смены фоновых причин и сырые reader/trace-события. Выводится одна короткая строка при переходе в OFF. Уже прочитанные события периода OFF не воспроизводятся задним числом после включения. Ошибки и обратная связь по уже отправленным действиям не скрываются.

## Что намеренно осталось

- KS включается кнопкой программы; F6 не управляет им, Esc не выключает. Insert открывает меню и временно приостанавливает ввод, сохраняя ON. End — выход.
- Если физически удерживается **сама клавиша выбранного KS-каста**, её не нажимаем и не отпускаем за пользователя. Это не общая пауза от любых клавиш.
- Подтверждённая занятость героя/канал, отсутствие валидной цели, геометрия, фокус, свежесть данных, CD и ожидание подтверждения сохраняют силу.
- Потеря фокуса вне меню приложения, неоднозначность/смена локального героя, длительная потеря данных и ошибка отправки по-прежнему могут выключить KS. Смерть уже включённого героя приостанавливает действие, а не снимает ON.
- Один общий sender и существующий приоритет защит над KS. Новых потоков отправки нет. Правила распознавания/защит Dodger, включая его собственные ограничения Enter/Tab, не переделывались. CK/WR не объявляются исправленными.
- Направленный каст перемещает курсор. Реальный ручной ввод, фокус и игра не образуют атомарную транзакцию с SendInput; абсолютной независимости или гарантии принятия каждого нажатия нет.

## Важно: чат

Чат и игровые меню всё ещё не определяются по состоянию игры. **После отпускания Enter KS может продолжить ввод при открытом чате. Перед перепиской выключай Killsteal кнопкой.** Enter/Tab теперь только временный запрет при удержании, а не определитель закрытия чата. Это явное следствие снятия прежнего автоматического OFF, а не реализованная поддержка чата.
